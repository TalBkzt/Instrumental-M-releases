Учёт заказов для мебельных и столярных цехов. Здесь лежат только сборки, исходный код закрыт.

## Что умеет

- **Заказы и клиенты** — детали с размерами и кромкой, статусы, оплата и долги, метки, папки.
- **Производство** — календарь сроков и доска по этапам.
- **Раскрой** — раскладка деталей на листы с учётом реза, пошаговый вид, экспорт в PDF и CorelDRAW (на Windows).
- **Импорт** — список деталей из Excel или с фотографии.
- **Каталог цветов** — RAL/NCS.
- **Команда** — общие заказы в рабочем пространстве.
- **Без интернета** — данные хранятся на устройстве и синхронизируются с облаком, когда сеть появляется.
- **6 языков** — русский, казахский, английский, турецкий, китайский, монгольский.

## Установка

Скачайте файл из [последнего релиза](https://github.com/TalBkzt/Instrumental-M-releases/releases/latest).

**Windows** — `Instrumental-M_Setup_vX.Y.Z.exe`. Обновления скачиваются в фоне и ставятся при закрытии программы.

**Android** — `Instrumental-M_vX.Y.Z.apk`. При первой установке Android попросит разрешить установку из этого
источника. Новые версии приложение предложит само.
